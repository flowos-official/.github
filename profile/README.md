## English

FlowOS is becoming the remote AI department for Korean manufacturers.

The people on a factory floor know exactly how the plant runs. Its systems know almost nothing of that, and nobody there can change them. AI models are already capable enough. What's missing is context: what the page doesn't say. You only get context from inside the plant.

| Part | What it does |
| --- | --- |
| FlowOS Connect | A small app on a plant computer. People just show how they work. |
| FlowOS Superbrain | The plant's one source of truth. |
| Human-approved execution | AI sorts each request, checks it against the plant's rules, writes the code and runs the tests. Before real records change, it's designed to stop for a person's approval. |

One remote AI department: a builder for the software, a defender at the door, and an advisor on what to do next. A plant's data is used only for that plant.

## 한국어

FlowOS는 국내 제조기업의 원격 AI 부서로 자리 잡고 있습니다.

현장 사람들은 공장이 어떻게 도는지 정확히 압니다. 하지만 시스템은 그걸 거의 모르고, 공장 안에는 고칠 사람도 없습니다. AI 모델은 이미 충분히 똑똑합니다. 진짜 문제는 AI의 성능이 아니라 현장의 맥락, 즉 문서에 적히지 않은 앞뒤 사정을 모른다는 점입니다. 이 맥락을 알려면 공장 안으로 들어가야 합니다.

| 구성 | 하는 일 |
| --- | --- |
| FlowOS Connect | 공장 컴퓨터에 깔고 평소 하던 일을 그대로 보여 주면 됩니다. |
| FlowOS Superbrain | 공장 곳곳에 흩어진 업무 기준을 하나로 모읍니다. |
| 사람이 승인하는 실행 | AI가 요청을 분류하고, 공장 규칙에 맞는지 확인한 뒤, 코드를 짜고 테스트를 돌립니다. 실제 데이터를 바꾸는 일은 사람이 승인하도록 설계합니다. |

원격 AI 부서가 필요한 소프트웨어를 만들고, 공장 데이터를 지키고, 어디부터 고칠지 조언합니다. 한 공장의 데이터는 그 공장 일에만 씁니다.
